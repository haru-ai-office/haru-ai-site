# 業務マニュアル整備 | 自主制作サンプル

**架空の業務を題材としたデモです。実際の現場手順として使用しないでください。**

## 想定課題
担当者ごとに異なる「朝の事務所開店準備」を共通手順に整理する。

## サンプル手順
1. 管理者が当日の開店担当者を確認する。
2. 指定された業務システムで当日の予約状況を確認する。
3. 備品の不足をチェックし、不足があれば所定の連絡先へ報告する。
4. 開店準備チェックリストに完了時刻と担当者を記録する。
5. 例外・不具合があれば独断で処理せず、管理者へ報告する。

## チェックリスト
- [ ] 担当者確認
- [ ] 予約状況確認
- [ ] 備品確認
- [ ] 不足・例外の報告
- [ ] 完了記録

## 納品条件
顧客提供の資料・聞き取り内容をもとに編集。安全、法令、品質に関わる実運用手順は顧客責任者の承認後に使用。
