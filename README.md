Public-facing landing page and original demonstrator samples only.

## Contents
- index.html: responsive Japanese service introduction and inquiry link
- samples/: fictional examples and proposed digital product details

## GitHub Pages setup
1. Open Settings > Pages in this repository.
2. Under Build and deployment choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for the GitHub Pages deployment to finish.
5. Verify the live page at https://haru-ai-office.github.io/haru-ai-site/ and test all sample links and the inquiry email.
